## 🛠️ Technology Behind The Portfolio

Clips Kinetics was crafted with modern web engineering to guarantee lightning performance and visual aesthetics:

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, React 19)
- **3D Graphics**: [Three.js](https://threejs.org/) + [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Motion & Dynamics**: [GSAP](https://gsap.com/) + ScrollTrigger
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom luxury dark tokens
- **Hosting**: [Vercel](https://vercel.com/) with global CDN edge routing
