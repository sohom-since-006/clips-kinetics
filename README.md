## 🌟 Highlights & Features

- **💎 Interactive 3D Crystal Play Logo**: Custom procedural Three.js / React Three Fiber scene featuring an interactive, mouse-tilting crystal play badge with ambient amber point lighting and fallbacks for low-power devices.
- **🎬 Zero-Friction Video Portfolio**: Click-to-load Google Drive embeds for short-form (9:16 reels) and long-form (16:9 YouTube/cinematic) videos. Only one video plays at a time with automatic memory management.
- **📸 Open for On-Location Video Shooting**: Dedicated packages for Car Deliveries, Wedding Highlights, House Warmings, Agomoni Cultural Shoots, and Ceremonies in Asansol and West Bengal.
- **⚡ 1-Click WhatsApp Lead Generation**: Every quote button throughout the site deep-links directly to WhatsApp with pre-filled custom inquiry text matching the exact service clicked.
- **🎨 Editorial Typography Suite**: Elegant pairing of Google Fonts (`Montserrat`, `Open Sans`, and `Alex Brush` script) styled on a high-contrast dark luxury background.
- **📱 100% Mobile Optimized**: Tested across screen sizes down to 360px with touch-responsive navigation and zero horizontal overflow.

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js**: v18.17+ or v20+
- **npm**: v9+

### 1. Clone the Repository
```bash
git clone https://github.com/sohom-since-006/clips-kinetics.git
cd clips-kinetics
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run Quality Checks
```bash
npm run validate   # Validate all site data and video configurations
npm run lint       # Run ESLint checks
npm run build      # Create production build
```
